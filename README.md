# NineSolsAPI-SaveUtils-ExampleMod


The NineSolsAPI-SaveUtils .DLL file (https://github.com/SierraFrey/NineSolsAPI-SaveUtils) needs to be added as a reference for this to compile.

In the file path on line 47 of the .csproj file, either have the DLL match the file path or replace it with your own file path.
